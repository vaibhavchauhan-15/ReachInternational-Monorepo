<objective>
Deliver the foundational offline mutation queue and network resilience engine for the Expo mobile app (per D-01, D-03, D-04, D-06, MOB-03).

Output: Core offline queue service (`OfflineQueueManager`), typed mutation models (`types.ts`), network connectivity hook (`useNetworkStatus`), and reactive queue subscriber hook (`useOfflineQueue`).

       - On failure, classify error type (per D-04, D-05, Pitfall 3):

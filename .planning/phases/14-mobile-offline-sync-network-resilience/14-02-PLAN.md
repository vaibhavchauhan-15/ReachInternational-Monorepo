<objective>
Integrate user-facing offline resilience into the Expo mobile application (per D-02, D-03, D-05, D-07, D-08, MOB-03).
Provides ambient network status banners, tactile optimistic machine log updates with 4-state status badges, and an interactive "Edit & Resubmit" collision resolution bottom sheet.

Purpose: Operators in the field receive immediate visual confirmation that their shift submission was safely queued offline, understand when sync is taking place, and can gracefully resolve time collisions if a server conflict occurs.
Output: UI components (`OfflineBanner`, `SyncStatusBadge`, `OfflineCollisionModal`) integrated into `_layout.tsx`, `operations.tsx`, and `MeterLogModal.tsx`.
</objective>
